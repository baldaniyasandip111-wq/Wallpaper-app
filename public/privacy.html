Wallpaper.app Privacy

Privacy-first by design.

What is stored

Favorites and recently viewed wallpaper IDs stay on your device/browser.

What is not collected

The current app does not use analytics, advertising trackers, tracking pixels, or a user profile system.

Permissions

Wallpaper features do not require contacts, microphone, camera, SMS, or precise location access.

Future features

Any feature that needs personal data should use data minimization, least privilege, clear disclosure, and user consent.
